# Responsive shell

- La navegación global conserva identidad y acceso al perfil.
- En escritorio puede haber regiones simultáneas; en móvil se vuelven una secuencia.
- Una ruta interna usa encabezado de trabajo compacto, contexto y acciones.
- El ancho de viewport y el de contenido se separan para evitar overflow.
- En escritorio amplio, el shell crece hasta un máximo legible; no queda congelado en
  una medida pensada para laptop ni se extiende hasta tocar los laterales.
- El lockup central se alinea con el eje del viewport, no con el espacio residual entre
  grupos de navegación y herramientas.
- Los popovers se convierten en paneles de flujo en pantallas estrechas.
