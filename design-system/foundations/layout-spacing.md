# Retícula y espaciado

- Contenido editorial: máximo `1240px`.
- Shell amplio: máximo `1420px`.
- Escritorio: margen mínimo `40px`; tablet `24px`; móvil `14–18px`.
- Breakpoints provisionales: `560px`, `860px`, `1180px`.
- Escala: `4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96`.
- Controles: 8–16 px; grupos: 16–24 px; regiones: 32–48 px; secciones: 64–96 px.

Un valor fuera de escala requiere una razón óptica o una composición local.
