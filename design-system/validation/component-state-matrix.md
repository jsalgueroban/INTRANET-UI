# Matriz de estados de componente

| Familia | Estados mínimos | Controles |
| --- | --- | --- |
| Acción | idle, hover, focus, active, disabled, busy | Nombre, foco, envío único |
| Campo | empty, filled, focus, invalid, disabled, readonly | Label, ayuda, error |
| Icon action | idle, hover, focus, disabled | Nombre accesible, 44 × 44 |
| Feedback | loading, empty, error, forbidden | Anuncio, recuperación |
| Shell | expanded, dragging, collapsed, interrupted | Puntero, teclado, zoom |
| Bandeja | closed, open, closing-reopened | Foco, Escape, exterior |
| Hub | resting, held, thrown, hidden, open | Captura, retorno, reduced motion |

Cada nueva variante debe completar esta matriz antes de reutilizarse fuera de su familia.
