# Matriz de regresión

| Área | Riesgo protegido | Evidencia requerida |
| --- | --- | --- |
| Tokens | Valor divergente o referencia rota | Generación reproducible |
| Tipografía | Fallback o salto de jerarquía | Carga y captura por viewport |
| Layout | Desborde, vacío entre secciones | Barrido de viewports y zoom |
| Controles | Hitbox, foco o contraste insuficiente | Teclado y estado visible |
| Motion | Parpadeo, reinicio o carrera | Interrupción y reentrada |
| Contenido | Texto genérico o técnico visible | Revisión editorial contextual |
| Assets | Ruta rota o marca alterada | Carga local y revisión visual |

Clasificación: bloqueante, material o menor. Un bloqueante impide publicar; uno material
requiere corrección o aceptación explícita; uno menor puede quedar registrado con owner.
